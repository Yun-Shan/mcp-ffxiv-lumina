# 战斗装备来源缺口与验收优先级

更新日期：2026-10-24。依据当前 Lumina MCP 原始表、固定 LuminaSupplemental 5.1.4、临时获取链和已保存的 Wiki 对照结果。本文收敛后续研究范围与验收要求，正式接口保持原状。

## P0：先使常见装备路线准确且可操作

| 缺口 | 当前已具备 | 需要补齐 | 验收要求 |
|---|---|---|---|
| 副本掉落定位 | 可区分 Boss 掉落、Boss 箱、场景箱及环节未知的副本关系；保留 Boss/箱子原始编号 | 道中与首领箱的可靠分类、缺失 Boss 关联、跨数据集重复箱子身份 | 能指出副本和具体环节；无法定位时明确未知，不把 DungeonBossId=0 当道中，不将重复记录累加为独立掉落 |
| 兑换材料完整来源 | 报价成本可按 AND 递归展开，按数量计算兑换批次 | 断章、零件、书籍、硬化剂/强化药等每种成本的全部已知上游；缺关系时保留诊断 | 任一必需材料无来源时整条报价仍未闭合；不能用另一材料已找到来源掩盖缺口 |
| 神典石装备与强化链 | 可按成本槽解析神典石身份和数量；诗学有三个副本奖励样本 | 其他神典石的获得机制、基础装备加强化材料、多阶段兑换、版本轮换及旧报价状态 | 区分货币身份与货币赚取；基础装备和强化材料共同参与；首次奖励与重复基础奖励分开 |
| NPC 与操作地点 | 特殊商店和报价身份已有结构，部分样本有独立 Wiki NPC 对照 | 通用 NPC 菜单链、区域/地图坐标、商店及单行报价条件 | 给出可执行的“去哪找谁、选哪个菜单、交什么”；同一报价的多个 NPC/地点聚合，不重复计作不同成本路线 |

## P1：补条件、数量语义和制作装备

| 缺口 | 需要补齐与验证 |
|---|---|
| 武器箱/装备箱条件 | 箱子与产物集合、开箱职业、等级/使用场景、HQ 标记。现阶段主要保留物品说明，不能认定任意职业开箱都得到目标装备。 |
| 周限与个人奖励规则 | 宝箱出现条件、个人领取资格、每周限制、分配方式、解锁任务/成就及限制是否随版本解除。原始数量或概率不直接换算为个人必需刷本次数。 |
| 一次性与历史可用性 | 固定/可选任务奖励、能否重复领取、旧装备停产或替代兑换、活动/地区差异。来源数组为空不能直接判定绝版。 |
| 制作战斗装备 | 扩展到按目标版本选定的制作武器、防具和饰品；读取全部材料与水晶、职业/等级、秘籍条件、HQ 支持和后续强化兑换。可制作 HQ 不等于必定 HQ。 |
| 行动前置和费用 | 任务前置、采集开放条件、雇员能力及探险币等目前主要保留为行动条件。按装备路线的实际依赖补充，明确展开停止的位置。 |

当前完整制作材料树只在赛加羚羊革魔导典这类定向样本中完成验证，不能据此宣布所有制作战斗装备已覆盖。秘籍与工票在制作路线确实依赖时纳入；收藏品和老主顾的子行读取异常仍是这一部分的技术阻塞。

## P2：扩展装备渠道与覆盖范围

- 金币购买及军票/PvP 等专用交易表：按机制分别建索引，保留价格、军衔/阵营等条件。金币商店 GilShopItem 子行读取异常尚未解决。
- 任务职业装备、成就领取、特殊强化武器和特殊内容装备：补多阶段前置及实际交互步骤，单个普通任务奖励字段不能代表全部渠道。
- 玩家交易：区分可交易与可上市场板；不推断实时库存或价格。制作装备可标明有证据支持的玩家交易渠道。
- 按版本和来源建立战斗装备验证集，覆盖武器、防具、饰品与不同职业组，避免只验证几件已知成功样本。

染剂、宠物、乐谱、纯收藏品和与战斗装备无关的远航/活动路线降低优先级。mode8 的 566 个隐式金币成本槽尚未全部核验；先筛出影响战斗装备的报价，不将总槽数当作战斗装备缺口数量。

## 首轮验收标准

结果至少能回答：

> 去哪个副本或获取地点 → 哪个 Boss／箱子／行动 → 得到什么装备、材料或箱子 → 需要多少 → 到哪里兑换／如何开箱 → 有什么限制。

按以下路线分别验收，不用“副本掉落”一个标签覆盖全部：

| 路线 | 必须保留的信息 |
|---|---|
| Boss 直接掉落装备 | 副本、Boss、直接奖励身份、数量证据、个人/周限状态 |
| Boss 箱或道中箱出装备 | 副本、箱子身份及位置、可靠的箱子分类、未确定字段和潜在重复证据 |
| 副本材料兑换装备 | 每种材料及数量、每种材料的来源、NPC/地点/菜单、解锁与兑换条件 |
| 副本装备箱开装备 | 箱子的副本来源、目标产物、开箱职业和使用条件；未知保证开箱数保持未知 |
| 神典石装备及强化 | 正确币种与数量、可验证的赚取机制、全部强化材料、旧/新报价与限制状态 |
| 制作及制作装备强化 | 完整配方和产量、材料 AND、秘籍/职业条件、HQ 能力与结果区别、后续兑换链 |

第一批扩展验证应按上述机制选取代表装备，再覆盖武器/防具/饰品；每个适用机制同时检查直接路线和替代路线。当前 10 件样本保留为回归集，不以新增成功样本替换既有失败或缺失结果。

报告分别统计“目标至少有一路径”“全部已知路线覆盖”“字段与 Wiki 一致”“未验证条件”。保持已有来源、缺数据、读取失败、尚未实现、历史来源和预算截断的区别。只有代币消耗数量可以直接由报价计算；随机箱、个人掉落、周限等未验证时，不输出保证刷本次数。
